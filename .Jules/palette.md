## 2024-05-18 - Contextual ARIA labels for list actions
**Learning:** In lists of items (like order histories), repeated action buttons (e.g., 'Abrir suporte', 'Avaliar') without contextual context create accessibility barriers for screen reader users, who hear the same generic action multiple times without knowing which item it applies to. Furthermore, if a button has dynamic visual text states (e.g., '{hasReviewed ? 'Sent' : 'Review'}'), the `aria-label` must dynamically match those same conditional states to prevent contradicting the visual label.
**Action:** Append contextual ARIA labels to buttons with dynamic text states using template literals (e.g., `aria-label={\`Abrir suporte para ${item.title}\`}`) to provide unique, descriptive context for screen readers. Ensure the `aria-label` matches visual text when dynamic states are used.
