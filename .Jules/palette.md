## 2024-08-17 - Contextual ARIA labels for repeated action buttons
**Learning:** In lists of items, repeated action buttons (e.g., 'Abrir suporte', 'Avaliar') need unique contextual ARIA labels (e.g., appended with the item's title) so screen readers can distinguish between them.
**Action:** Always use template literals to append unique identifiers (like item title) to ARIA labels for repeated action buttons in lists.
